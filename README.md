# MaxxTermux

Open-source SSH and terminal client for Android, by Anshuman_X (maxxcodebug).
UI language: AX Design (see `docs/AX_DESIGN.md`).

## Status
v0.1: project skeleton, AX Design tokens and components, Home screen with sample data.

## Build
1. Install Android Studio (or JDK 17 and the Android SDK).
2. In this folder run `gradle wrapper --gradle-version 8.9` once to create `gradlew`.
3. `./gradlew assembleDebug`

## Roadmap
- Shell screen with a terminal emulator written for this project
- SSH layer
- Keys, Snippets and Settings screens (progress style picker)
